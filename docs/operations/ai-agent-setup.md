# AI Agent Setup

This project includes Laravel Boost as a development-only dependency so AI coding agents can work with Laravel, Filament, Livewire, Tailwind, Sail, and PHPUnit using version-aware project guidance.

Laravel Boost is for development workflow only. Runtime AI features should use the provider abstraction in `docs/architecture/ai-provider-abstraction.md`, with `laravel/ai` preferred for future dashboard-driven AI features.

## Installed Tooling

- `laravel/boost` is installed in `require-dev`.
- `boost.json` records enabled Boost features.
- `.mcp.json` exposes the `laravel-boost` MCP server through `php artisan boost:mcp`.
- `AGENTS.md` and `CLAUDE.md` contain generated Laravel Boost guidelines.
- `.agents/skills/` contains Codex skills generated by Boost.
- `.claude/skills/` contains Claude Code skills generated by Boost.
- `.junie/` contains Junie guidelines, skills, and MCP config generated by Boost.

## First Files For Agents To Read

AI agents should read these files before implementing meaningful changes:

1. `AGENTS.md` or `CLAUDE.md` for generated Boost guidance.
2. `agents/claude.md` for project-specific conventions, documentation rules, branch naming, and debt tracking.
3. `docs/README.md` for the durable project documentation index.
4. The relevant architecture, implementation, operations, testing, or tech-debt file for the requested area.

For Laravel, Filament, Livewire, Tailwind, queue, migration, test, or Sail work, agents should use Boost documentation search and project inspection tools when the MCP server is available.

## Codex MCP

The repository-level `.mcp.json` defines the Boost MCP server:

```json
{
    "mcpServers": {
        "laravel-boost": {
            "command": "php",
            "args": [
                "artisan",
                "boost:mcp"
            ]
        }
    }
}
```

If an agent does not automatically detect `.mcp.json`, register the server manually from the repository root:

```bash
codex mcp add laravel-boost -- php artisan boost:mcp
```

When working inside Sail-only environments, run the agent from the host project root when possible. The generated MCP command expects host PHP to run `artisan`. If host PHP is unavailable, use the normal Sail commands for implementation and tests.

## Updating Boost Assets

After upgrading Laravel, Filament, Livewire, Tailwind, PHPUnit, or Boost itself, refresh generated agent assets:

```bash
composer update laravel/boost --with-dependencies
php artisan boost:install --guidelines --skills --mcp --no-interaction
```

Review the generated diff before committing. Boost-generated files can change substantially when package versions change.

## Agent Working Rules

- Treat Boost as dev tooling, not application runtime.
- Use Boost search docs before Laravel-specific code changes when available.
- Keep runtime AI credentials and model routing in dashboard-owned encrypted tables in the future AI provider phase.
- Do not add real API keys, OAuth secrets, model credentials, or mailbox data to prompts, docs, tests, commits, or generated fixtures.
- Prefer PHPUnit tests, factories, and Laravel fakes over ad hoc scripts.
- Run the smallest meaningful verification set before reporting completion.

## Verification

For agent-tooling-only changes, run:

```bash
composer validate
composer audit
php artisan boost:mcp --help
php artisan test --compact
git diff --check
```

For PHP code changes, also run:

```bash
./vendor/bin/pint --dirty --format agent
```
